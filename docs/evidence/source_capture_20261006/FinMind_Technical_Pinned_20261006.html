    台股總覽 TaiwanStockInfo¶

    • 這張資料表主要是列出台灣所有，上市、上櫃、興櫃，的股票名稱，代碼和產業類別！
    • 資料更新時間 每天 1:30，實際更新時間以 API 資料為主
    轉板的股票會保留多列：請取 date 最新的那一列作為目前市場別

    同一檔股票若曾由興櫃轉上市 / 上櫃，本表會同時保留 emerging 與 twse / tpex 兩列；emerging 那列的 date 停在該股離開興櫃的日期，twse / tpex 那列的 date 才是當日。因此直接用 type == "emerging" 篩選會把已轉板的個股一起選進來，請取同一 stock_id 中 date 最新的那一列。此點在使用 TaiwanStockPriceTick、TaiwanStockKBar 時特別重要，因為這兩張表的 volume 單位依市場別而異（上市 / 上櫃為「張」、興櫃為「股」）。

    台股權證標的對照表 TaiwanStockInfoWithWarrantSummary(只限 sponsor 使用)¶

    • 提供權證標的對照表。( 由於包含權證資料，資料量大，約需等一分鐘時間。 )
    • 涵蓋上市 (TWSE) 與上櫃 (TPEX) 權證的標的（母股 target_stock_id）對照；上櫃權證的標的對照歷史回溯至 2011-01-03，可用母股代碼反查其對應權證（含已到期、代碼重用的歷史權證）。
    • 資料更新時間 每天 1:30，實際更新時間以 API 資料為主
    同一檔權證代號可能對應不同的標的母股

    權證有到期日，同一個權證代號 (stock_id) 到期下市後，該代號會被回收、重新發行給掛在不同母股的新權證。因此同一個 stock_id 在本資料表中可能出現多筆，各自對應到不同的標的母股 (target_stock_id)，並有各自的 date（上市日期）與 end_date（最後交易日）。

    判斷某個權證代號在特定日期對應哪一檔母股時，請以「查詢日期落在該筆的 date ～ end_date 區間內」為準；不同時期的同代號權證會因區間不重疊而自然區分。

    股價日成交資訊 TaiwanStockPrice¶

    • 提供台股，上市、上櫃、興櫃，的股票日成交資訊！
    • 資料區間：1994-10-01 ~ now
    • 資料更新時間 星期一至五 17:30，實際更新時間以 API 資料為主
    興櫃個股：open 為「前日均價」，可能落在當日高低之外（非資料錯誤）

    興櫃股票採議價交易、沒有開盤價。因此本表對興櫃個股，open 欄填入的是 「前日均價」，而非當日開盤價；max / min / close 仍為當日最高 / 最低 / 最後成交價，皆正確可用。

    所以興櫃個股在波動較大時，常出現 open 高於 max 或低於 min 的情形，這是欄位定義差異、非資料錯誤。畫 K 線時可改用 max / min / close，或將 open 視為前日均價處理。

    範例：6515 穎崴 2020-03-19（當時為興櫃）→ open=218.06、max=200、min=170、close=174.9，其中 218.06 即當日的「前日均價」。該股後轉上市，上市後資料即正常。

    另一種情形：興櫃掛牌首日 open=0。 既然興櫃 open 是「前日均價」，那麼一檔股票第一個交易日因為沒有「前一日」可取均價，open 便顯示為 0；max / min / close 仍為當日正確值，從隔日起 open 就會有正常的前日均價。這同樣是欄位定義差異、非資料錯誤。

    範例：8272 全景 2023-10-17（興櫃掛牌首日）→ open=0、max=136、min=112.5、close=130；隔日 2023-10-18 open=129.39，即 2023-10-17 的均價。此規則對 TaiwanStockPriceAdj（還原股價）同樣成立——還原價為原始價乘還原係數，0 會原樣沿用。

    個股當日無公告成交價時，open / max / min / close 皆為 0（非資料錯誤）

    證交所、櫃買中心的每日個股行情，對於當日沒有公告成交價的個股，開高低收會以 -- 表示。本表照原始公告轉為數值 0，因此該個股當日的 open / max / min / close / spread 會同時為 0。這是原始公告即無價格，不是抓取遺漏。

    此情形任何市場別都可能發生（上市、上櫃、興櫃皆然），與前述興櫃 open 的欄位定義無關。個股停止買賣、當日全無成交，或當日僅有零星成交而未形成公告價格時，都會落在這一類。

    範例一（完全無成交）：2317 鴻海 2025-07-30 → Trading_Volume=0、open/max/min/close 皆為 0；證交所該日原始公告即為「成交股數 0、開高低收 --」。前一交易日 2025-07-29（close=171.5）與次一交易日 2025-07-31（close=178）資料均正常。

    範例二（有成交量但無公告價格）：9929 秋雨 2025-07-31 → Trading_Volume=451，但 open/max/min/close 仍為 0；證交所原始公告即為「成交股數 451、開高低收 --」。

    判斷方式：由於範例二存在，請勿只用 Trading_Volume > 0 篩選，該條件會漏掉「有量但無價」的列。建議直接以價格欄位判斷：

    df = df[df["close"] > 0]          # 只保留有公告成交價的交易日
# 或改以前一交易日收盤價填補
df["close"] = df["close"].replace(0, method="ffill")

    台灣還原股價資料表 TaiwanStockPriceAdj (只限 backer、sponsor 會員使用)¶

    • 資料區間：1994-10-01 ~ now

    還原因子的更新時點與基準日

    還原價為回溯計算：以資料中最新一個交易日為基準，往前累乘還原係數。因此事件當日的還原價恆等於該日的原始價，調整反映在該日「之前」的歷史資料上。

    若事件的排定日遇全市場休市（例如颱風停市）而順延，還原調整以實際發生交易的日期為準，而非原定日期。

    台灣股價歷史逐筆資料表 TaiwanStockPriceTick (只限 backer、sponsor 會員使用)¶

    (由於資料量過大，單次請求只提供一天一檔個股資料)

    • 資料區間：2018-12-07 ~ now。
    • 輸入 dataset、stock_id、start_date 參數，會回傳 start_date 當天資料。
    • 資料更新時間 星期一至五 15:30，實際更新時間以 API 資料為主。
    • 部分資料缺失，缺失日期為：2018-12-22、2019-02-20、2019-02-21、2019-02-22；另 2019-05-16 僅有少數 ETF 的資料。
    • 開啟 Async 功能，可大幅縮短資料更新時間，colab 實測 2236 檔股票，只需 3 分 40 秒即可完成下載。
    TickType 內外盤標記已全面修正（2018-12-07 ~ 2023-03-10）

    2023-03-13 以前的資料，舊版把無法判定內外盤的成交一律標記為 1（外盤），使外盤占比明顯偏高。此區間的全部交易日已重新產製，改用與 2023-03-13 之後一致的判定規則。若您先前已下載過這些日期的資料，請重新取得。

    volume 單位依市場別而異：上市 / 上櫃為「張」、興櫃為「股」

    台股分 K 資料表 TaiwanStockKBar (只限 sponsor 會員使用)¶

    (由於資料量過大，單次請求只提供一天資料)

    • 資料區間：個股 2019-01-01 ~ now；加權指數（data_id="TAIEX"）2005-01-03 ~ now
    • 資料更新時間 星期一至五 15:50，實際更新時間以 API 資料為主
    • 部分資料缺失，缺失日期為：2019-02-20、2019-02-21、2019-02-22（這三天僅有加權指數 TAIEX 分 K，無個股資料）；另 2019-05-16 個股僅有少數 ETF 的資料。
    • 開啟 Async 功能，可大幅縮短資料更新時間，colab 實測 2175 檔股票，只需 2 分 31 秒即可完成下載。
    本表也提供加權指數（TAIEX）分 K

    除了個股，把 data_id 帶 TAIEX 就能取得臺灣加權股價指數的分 K：

    df = api.taiwan_stock_kbar(stock_id="TAIEX", date="2026-08-19")
    • 資料區間 2005-01-03 ~ now，比個股分 K（2019-01-01 起）更長
    • 每個交易日 271 筆，涵蓋 09:00:00 ~ 13:30:00 每分鐘一筆
    • 指數本身沒有成交量，因此 volume 固定為 0；open / high / low / close 為該分鐘內的指數值
    • 補行交易的星期六同樣有資料
    volume 單位依市場別而異：上市 / 上櫃為「張」、興櫃為「股」

    本表 volume 沿用各市場的原始交易單位：上市、上櫃個股為「張」（1 張 = 1,000 股）；興櫃個股為「股」，與 TaiwanStockPriceTick（逐筆）規則相同。判斷市場別的方式與注意事項（已轉板股票在 TaiwanStockInfo 會保留兩列），請見 TaiwanStockPriceTick 章節的同名說明。

    上市 / 上櫃個股 13:33 的分 K：延緩收盤的收盤撮合

    上市、上櫃個股若當日收盤集合競價觸發價格穩定措施，收盤撮合會延後，撮合時間落在 13:33，因此該日會多出一根 13:33 的分 K。這根分 K 是當日正式的收盤撮合結果，屬有效成交，請保留；其 close 等於當日官方收盤價（TaiwanStockPrice 的 close），可用此逐日判定是否為延緩收盤日。

    興櫃個股為連續議價、交易至 15:00，13:33 只是盤中的一般分鐘，與延緩收盤無關；股票可能由興櫃轉上市 / 上櫃，請依「當日」市場別判斷。
