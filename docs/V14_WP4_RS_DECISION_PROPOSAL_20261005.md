# R23 比較口徑與接續決策提案

狀態：研究提案，尚未成為正式交易規格。

## 本次建議

建議以「相對累積報酬」作為後續 R23 研究的主要顯示值，另列個股絕對報酬及報酬差。其優點是直接表示個股與基準累積成長比值的變化，且可用同一組期初、期末觀測重現；報酬差以百分點顯示，避免混淆。此選擇是本次研究建議，並非既有規格要求，也不設定買賣門檻。

## 比較口徑選項

| 選項 | 必須一致的條件 | 本次判定 |
|---|---|---|
| 價格報酬對價格報酬 | 公司行動處理方式、同一收盤時點、幣別、觀測窗口 | 可研究；不能默認未調整個股在拆股等事件前後可比較 |
| 總報酬對總報酬 | 股利及再投資定義、公司行動、幣別、窗口 | 可研究；需要兩端都有可驗證的總報酬資料 |
| 個股總報酬對基準價格報酬 | 經濟口徑不同 | 不建議作為同口徑 RS 比較 |
| 不明調整序列對不明基準 | 缺少來源與定義 | 保留缺口，不計入正式結果 |

matching adjustment_type 字串僅是目前合成原型的檢查，不能替代上述條件的證據。原型尚無實際交易日曆、幣別、時區或來源驗證。

## 正式實作前需要的證據

1. 基準：明確指數名稱、唯一識別碼、官方定義與價格／總報酬類型；保留文件日期及來源。
2. 個股：明確資料來源、欄位契約、公司行動與股利處理方法；保留可重現樣本。
3. 時間：指定市場時區、收盤定義、共同交易日曆；缺值和停牌政策需明訂，不以交集悄悄縮短窗口。
4. 期間：先指定研究窗口與所需觀測數，不推測既有 R23 的期間。
5. 用途：單檔相對比較先行；跨股排名另需同基準、同期間、可追溯母體及排除原因。正值不等於絕對獲利或交易許可。
6. 驗收：將来源樣本、預期計算及非法資料拒絕案例納入正式測試，再審查接入點。

## 原型補強與驗證

本次發現：兩端累積比值各自為正有限數，彼此相除仍可能下溢為零，造成相對報酬被錯算為 -100%。已增加比值下溢拒絕及對應測試。研究測試累計 17 項通過。
