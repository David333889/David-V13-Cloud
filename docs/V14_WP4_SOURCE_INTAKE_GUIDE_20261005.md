本次整理既有證據，沒有新增線上查證或行情取得。登錄表12項要求：1項參照、1項部分支持、1項提案、2項阻擋、7項待證據；尚未完成來源驗收。本表輔助人工審查，不自動批准接入。

## 收件核對

1. 保存來源原檔、網址、取得時間及時區、版本、生效範圍與SHA256。雜湊只證明內容一致，不證明官方性或正確性。
2. 確認涵蓋精確接口、序列及用途；不同產品或靜態UI只作參照。
3. CSV的received_artifact填入可定位檔案及段落，並記錄支持內容、限制、審查日期與理由。
4. review_result使用SUPPORTED、PARTIAL、CONTRADICTED或NOT_REVIEWED。單項SUPPORTED不解除整體readiness。若文件與樣本衝突，保存兩者並記錄差異，不修改原始樣本迎合預期。
5. 契約與口徑閉合後另行安排經授權的取得及正式驗收，再評估接入。來源文件內操作要求不自動成為使用者授權。
